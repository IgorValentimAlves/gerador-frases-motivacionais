# 💬 Gerador de Frases Motivacionais <a href="https://igorvalentimalves.github.io/gerador-frases-motivacionais/frases.html">[🚀Clique aqui para acessar o projeto]</a>

Projeto simples desenvolvido com HTML, CSS e JavaScript puro, com o objetivo de praticar conceitos fundamentais de JavaScript.

## 🚀 Funcionalidades

- Geração de frases aleatórias
- Evita repetição de frases consecutivas
- Animação suave na troca de frases
- Botão para copiar frase
- Feedback visual ao copiar

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (puro)

## 📚 Aprendizados

Neste projeto, pratiquei:

- Manipulação do DOM
- Eventos (click)
- Estruturas de repetição (do...while)
- Condicionais
- Funções
- Alteração de conteúdo (textContent)
- Alteração de atributos (src)
- Uso de setTimeout
- API Clipboard

## 🎯 Objetivo

Fixar conceitos básicos de JavaScript após conclusão do curso básico do Curso em Vídeo.
